# 実態調査の練習（W-01・T-01〜T-03）

これは**実態調査**（D82）の練習です。**解析器の精度を測る練習ではありません。**

| | 実態調査（このフォルダ） | 解析器の精度（矛）・見落としの判定（`evidence/practice_v4/`） |
|---|---|---|
| 問い | このツールの宣言（`readOnlyHint: true`）は正しいか。ツールを呼ぶと、D1 に反する動作に届くか | 解析器が出した矛は正しいか（精度）／解析器が見落とした動作はあるか |
| 選び方 | 宣言を付けたツールの名簿（`scripts/survey_roster.py`。**解析器を使わない**）から無作為に選ぶ（D85） | 解析器が矛を出した組・出さなかったツールから選ぶ |
| 解析器 | **使わない・出力を見ない** | 出力を見て、その正誤を決める |
| 答え | `違反` / `違反でない` / `不明` / `対象外`（と別に数える `違反（深さ 4 の外）`） | 正 / 誤 / 不明、見落とし / 反する動作は無い / … |
| 論文で言うこと | 宣言したツールのうち、宣言に反するものの割合（下限） | 解析器の精度・見落としの多さ |

**手引き 18 節（見落としの判定）を引く理由**: D82 は、実態調査の**読み方**を見落としの判定の読み方と同じにすると決めました（解析器の
出力を見ずに、ツールの本体から深さ 4 まで読み、反しうる動作を書き出す）。借りるのは読み方だけで、答える問いは「このツールは宣言に
反するか」です。手順書は 18 節のうち解析器に関わる段（出力を見る段・見落としの原因・`cause` の欄・`不明（打ち切り）`）を外して
います（`manual/02_steps.md` の冒頭）。

## 始め方

1. **`manual/README.md`**（手順書の地図）を読む。
2. **`manual/05_practice.md`**（練習の進め方）を読む。
3. **`manual/01_setup.md`** のとおりに準備する（木を取る・表を写す・エディタの AI を切る・開かないものを確かめる・手引きを読む）。
4. W-01（練習の練習）→ 振り返り → T-01（→ T-02 → T-03）の順に、`manual/02_steps.md` の段 0〜11 をなぞって判定する。
5. 送るものは `manual/05_practice.md` の 5.7。

## この練習の限界（2026-10-09）

- **目隠し**: 手順書（`manual/`）・FAQ・O48 の仮の扱いは、本記録者（AI）が 4 件の参考の答えを書いたのと同じ作業の中で書いた。
  点検（5 つの観点の敵対的な点検ほか、2026-10-09）で、練習の件に近すぎる例と一文を外した（何を外したかは、各件の答えのファイルの
  末尾に書いた。ここに書くと答えの手がかりになる）。それでも、仮の扱いの一部は練習の件で出会った形をきっかけに足したもので、
  T の件ではその形に前もって答えが用意されている。どれがどの件から来たかは、各件の答えのファイルの末尾に書いた。
- **向き**: T の時間は、本番（前もって決めていない形に出会う）より**短く出うる**。B1 では「この手順書があるときの時間」として使い、
  この向きを限界として書く。
- **W-01 の選び方**: W-01 は、v4 の見落としの判定（解析器の出力を使う判定）の件から、手順をなぞりやすいものとして選んだ。本番の
  実態調査は解析器を使わない名簿から選ぶので、この点は本番と違う（T-01〜T-03 は本番と同じ選び方）。W-01 の時間は B1 に使わない。
- **練習のあいだに repo の中のファイルを書き換えない**（`docs/preregistration.md` の §5 を含む）。手引き 22 節の事例は、ワークシートの
  J 節に書いて送る（`manual/05_practice.md` の 5.7）。
- 2026-10-10 に、精度・見落としの練習（`evidence/practice_v4/`）と同じフォルダにあったのをこのフォルダに分けた（中身は同じ）。
