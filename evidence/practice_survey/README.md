# 実態調査の練習（W-01・T-01〜T-03）

これは**実態調査**（D82）の練習です。**解析器の精度を測る練習ではありません。**

| | 実態調査（このフォルダ） | 解析器の精度（矛）・見落としの判定（`evidence/practice_v4/`） |
|---|---|---|
| 問い | このツールの宣言（`readOnlyHint: true`）は正しいか。ツールを呼ぶと、D1 に反する動作に届くか | 解析器が出した矛は正しいか（精度）／解析器が見落とした動作はあるか |
| 選び方 | 宣言を付けたツールの名簿（`scripts/survey_roster.py`。**解析器を使わない**）から無作為に選ぶ（D85） | 解析器の出力をもとに選ぶ |
| 解析器 | **使わない・出力を見ない** | 出力を見て、その正誤を決める |
| 答え | `違反` / `違反でない` / `不明` / `対象外`（と別に数える `違反（深さ 4 の外）`） | 正 / 誤 / 不明、見落とし / 反する動作は無い / … |
| 論文で言うこと | D1 を明示したサーバから無作為に 1 ツールを選んだとき、そのツールが D1 に反する割合（下限。D82 の 6） | 解析器の精度・見落としの多さ |

実態調査の判定を**全部終えた後**で、本番ではそのラベルを解析器の出力と突き合わせ、解析器の再現率とツール単位の精度にも使います
（D82 の 2。矛かつ違反の件は、解析器の指した位置が違反かも判定する）。これは実態調査の判定とは別の、後の段で、**この練習ではしません**。

**手引き 18 節（見落としの判定）を引く理由**: D82 は「手順は見落としの判定（手引き 18 節）と同じ」と決めました。ただし、答える問いは
「このツールは宣言に反するか」で、解析器の見落としを探すのではありません。手順書（`manual/02_steps.md` の冒頭「18 節との違い」）は
18 節を次のように分けて使います。

| 18 節のうち | 実態調査で |
|---|---|
| 読み方（解析器の出力を見ずに、本体から深さ 4 まで読み、wrapper も読む。18.2 の 1〜3）、深さ 4 の外（18.3）、ラベルの取り方（18.2 の 7）、AI の点検（18.2 の 8）、記録の欄の考え方（18.4） | **使う** |
| 対象の決め方（18.1 の「矛が 1 件も出ていないツール」）、解析器の出力を見る段（18.2 の 4）、5 つの結果（「解析器が不として出している」など）と見落としの原因（18.2 の 5・6、`cause`・`output_found`）、`不明（打ち切り）` | **使わない**（対象は名簿の抜き取り、答えは `違反` / `違反でない` / `不明` / `対象外`） |
| 「反しうる動作をすべて書き出す」（18.2 の 3） | D82 の「最初の違反で止めてよい」を採る（止めるかは練習の前に決める） |

## 始め方

1. **`manual/README.md`**（手順書の地図）を読む。
2. **`manual/05_practice.md`**（練習の進め方）を読む。
3. **`manual/01_setup.md`** のとおりに準備する（木を取る・表を写す・エディタの AI を切る・開かないものを確かめる・手引きを読む）。
4. W-01（練習の練習）→ 振り返り → T-01（→ T-02 → T-03）の順に、`manual/02_steps.md` の段 0〜11 をなぞって判定する。
5. 送るものは `manual/05_practice.md` の 5.7。

## この練習の限界（2026-10-09）

- **目隠し**: 手順書（`manual/`）・FAQ・O48 の仮の扱いは、本記録者（AI）が 4 件の参考の答えを書いたのと同じ作業の中で書いた。
  点検（5 つの観点の敵対的な点検ほか、2026-10-09）で、練習の件に近すぎる例と一文を外した（何を外したかは、各件の答えのファイルの
  末尾に書いた。ここに書くと答えの手がかりになる）。それでも、仮の扱いの一部は練習の件で出会った形をきっかけに足したもので、
  T の件ではその形に前もって答えが用意されている。どれがどの件から来たかは、各件の答えのファイルの末尾に書いた。
- **向き**: T の時間は、本番（前もって決めていない形に出会う）より**短く出うる**。B1 では「この手順書があるときの時間」として使い、
  この向きを限界として書く。
- **W-01 の選び方**: W-01 は T と違い、本番の名簿の無作為抽出ではなく、手順をなぞる練習のために選んだ（選び方は W-01 を終えた後に
  開く答えのファイルの末尾）。W-01 の時間は B1 に使わない。
- **T-01〜T-03 の選び方**: 名簿の規則（D85）と抜き取りの手順は本番と同じ。ただし枠から、前に判定・文書化した木（解析器の出力で
  選んだ v4 の抜き取りの木を含む）と学生が見た木を除いた。抜き取りの列の 1 番目は `unmapped`（1 つの宣言を複数のツールが使う）で、
  選び方の規則が未決（O48 (5)）なので飛ばした（本番なら飛ばさず、判定者がツールを決める。D85 の 3）。
- **練習のあいだに repo の中のファイルを書き換えない**（`docs/preregistration.md` の §5 を含む）。手引き 22 節の事例は、ワークシートの
  J 節に書いて送る（`manual/05_practice.md` の 5.7）。
- 2026-10-10 に、精度・見落としの練習（`evidence/practice_v4/`）と同じフォルダにあったのをこのフォルダに分けた。あわせて、手順書の
  振り返りで解析器の出力を見る段を任意の参考にした（ほかの手順は同じ）。
