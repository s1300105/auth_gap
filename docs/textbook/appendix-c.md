# 付録 C 決定の年表

## この付録の使い方

### 一言で言うと

`docs/decisions.md` の決定 D1〜D71 を、**決めた時期の順**に 1 行ずつまとめた年表です。最終評価に直接効く D65〜D71 は、項目ごとに「決めた中身」と「判定や集計でどう効くか」を詳しく書きました。最後に、関係する逸脱（事前登録から外れた変更）と、未決事項 O の今の状態を表にしました。

### たとえ話 — 家の改築の記録帳

古い家を何度も改築してきた家族を思い浮かべてください。「台所の壁を抜いた（なぜなら狭かったから）」「その後、柱が足りないと分かって梁を足した」。記録帳があれば、今の家の形が「なぜこうなっているのか」をたどれます。記録帳が無ければ、「この柱は抜いてよいのか」が分かりません。決定の年表は、この研究の改築の記録帳です。

### 小さな例 — 1 行の読み方

| 決定 | 日付 | 要点 | この本の章 |
|---|---|---|---|
| D54 | 2026-09-24 | `MAX_DEPTH` を 3 → 4 に上げる（学生の決定。逸脱 #17）。深さ 3 → 4 で DB の未解決率 24.6% → 17.6%、CONTRADICTION 85 → 146、消えたものは 0（母集団 v2） | 第 15・27 章 |

この行は、「2026-09-24 に、学生が深さの上限を 4 に決めた。事前登録からの逸脱 #17 として記録した。数字は開発用の v2 のもので、論文の数字ではない。説明は[第 15 章](ch15.md)と[第 27 章](ch27.md)」と読みます。

### 一歩ずつ — 欄の意味

- **決定**: `docs/decisions.md` の見出しの番号。
- **日付**: D40 以降は見出しに書かれた日付。D1〜D39 は見出しに日付が無いので、**その決定が決定の記録に初めて現れたコミットの日付**（`git log -S` で確かめた）を書きました。D1〜D19 はどれも 2026-09-14 のコミットに初めて現れますが、それぞれを決めた日とは限りません。
- **要点**: 見出しと本文の要約。数字は原典の値で、どれも開発用のデータ（v2・v3）か中間検証（v4）のものです。論文には使いません。
- **この本の章**: その決定を説明した章。「—」はこの本では扱っていない決定です。

### なぜ年表が要るのか

判定の規則の多くは、それだけを読むと「なぜこんな細かい決まりがあるのか」が分かりません。たとえば「lifespan の初期化は誤、`main()` の初期化は正」（D67 の 2）は、v4 の誤の大半がこの形だったこと（D66）と、解析器を直さないと決めていたこと（D66 の 1・2）を知って、はじめて意味が通ります。年表で前後をたどると、規則の理由が見えます。

### よくある誤解・つまずき

- **決定の D1〜D4 と宣言の D1〜D4 を取り違える**: 決定 D1〜D4（語彙の拡張、G12 の理由、D_op、A1/A2 の期待タプル）は、宣言の D1〜D4（`readOnlyHint` など）とは無関係です。この本で「D1」とだけ書けば宣言です。
- **`docs/decisions.md` が番号順に並んでいると思う**: 並びは D39〜D20、D1〜D16、D19〜D17、D40〜D71 の順です。番号で探すときは `grep -n '^## D67' docs/decisions.md` のように見出しで探してください。
- **年表の要約を決定の本文の代わりに使う**: 要約は案内です。判定や論文で引くときは、必ず `docs/decisions.md` の本文を開いてください。
- **「推奨」と「決定」を混ぜる**: 多くの決定は、本記録者が選択肢と推奨を示し、学生が選んだものです。決めたのは学生です（[第 0 章](ch00.md)）。

### 手作業ではどう使うか

判定の途中で「この規則はなぜこうなっているのか」と迷ったら、[付録 E](appendix-e.md) の該当の行に書いた決定の番号を、この年表で引きます。D65〜D71 なら C.2 に詳しい説明があります。それでも足りなければ、`docs/decisions.md` の本文と、[第 46 章](ch46.md)（決定を 5 段で読む章）を開きます。

### この節のまとめ

- D1〜D71 を時期の順に並べた。D1〜D39 の日付は記録に初めて現れたコミットの日付。
- D65〜D71 は C.2 で項目ごとに詳しく。
- 決定の D1〜D4 と宣言の D1〜D4 は別物。原典は番号順に並んでいない。

### D70（2026-10-01）段階 0 の残り

1. **「1 木 3 件まで」は宣言ごと**（0-2 の (a)）。同じ木から D1 で 3 件、D2 で 3 件、…を選ぶ。走査と件数の記録（全数）は変わらない。理由: D1〜D4 は別々の主張として報告する（D62）ので、確かめる対象も宣言ごとに選ぶ。宣言をまたいで選ぶと、ある木のある宣言が偶然 1 件も判定されず、木の単位の数字が欠ける。

### D71（2026-10-01）解析器は自前のまま — と、その訂正

学生の問い「使える部分は既存のツールを使ったほうがよいのでは」に、本記録者が部品ごとに整理して示しました。
