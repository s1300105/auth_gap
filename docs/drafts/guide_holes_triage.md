# 判定の手引き（下書き）の穴 155 個と食い違い 13 件の仕分け

`docs/drafts/guide_decision_sheet.md`（決定シート）の元の表。**学生は読まなくてよい。** 決定シートの答えを確かめたいときだけ引く。

- 処置は 5 つのどれか 1 つ。
  - **重複**: 別の穴と同じ。残した穴の番号を書く。
  - **手引きで決まっている**: 手引きの文が決めている。行と、決めている言葉を引く。読み方で割れうるものはここに入れていない。
  - **記録の形**: 正 / 誤 / 不明・見落としの結果・(A)(B)(C)・ラベル・原因を変えず、記録の欄・置き場・書き方・運用の順だけに効く。既定を 1 つ置いた（決定シートの「一括で承認」(i) の番号）。
  - **まれ**: 結果に効きうるが、開発用のデータ（v4）で出会っていないか、決め手になった件が 0。数と出典を書いた。出会ったら手引き 22 節（不明にして事前登録 §5 に記録）。
  - **決める**: 正 / 誤・(B)(C)・ラベル・原因に効き、v4 で出会っているか、数えられなかったもの。決定シートの問の番号を書いた。
