#### (d) 抜き取り（D69、D70 の 1・2・7）

- **矛**: D1〜D4 の**宣言ごと**に、次のように選ぶ（D70 の 1）。

  - 各木から最大 3 件を seed ① で選ぶ。3 件に満たない木は全件。

#### (e) 判定（D67 の 4、D68、D70 の 3）

- 判定の基準は `docs/final_judging_guide.md`。この節と同じコミットで封をする。
- **AI（LLM）は使わない**。判定・原ソースを読む補助・記録のどれにも使わない（D70 の 3）。
- 判定の根拠（ファイルと行の連なり）を全件残して公開する。1 件ごとにかかった分数を記録する。
- **到達**: ツールの呼び出しで届きうるなら到達するとする（D68 の 1）。
  - 条件の種類を記録する: なし / 引数 / 初回 / 失敗・期限切れ / 外部の状態 / 運用者の設定 / 起動の方法。
  - 主の数 (A) は条件を問わない。
  - 併記 (B) は、運用者が決める条件（運用者の設定・起動の方法）でしか届かないものを除いた数。
  - 併記 (C) は、条件なしで届くものだけの数。
- **起動時の初期化**（D67 の 2）: 起動の方法はコードだけから決める。
  - 初期化が `main()` / `if __name__ == "__main__":` の中だけにあるなら、到達する。
  - lifespan の中、またはモジュールの読み込み時にあるなら、到達しない。
  - 読み切れなければ不明。
- **深さ 4 より奥の違反**（D68 の 2）: 見落としの判定で読むのは深さ 4 まで。それより奥で見つけた違反は「見落とし（深さ 4 の外）」
  として別に記録し、主の見落としの数に入れず併記する。
- **ラベル**（D67 の 1、D68 の 3）: 重みは付けない。
  - D1・D2・D4 の正と見落とし、不の中身の違反には、書き込み先の種類を付ける: 相手側の状態 / データベース / 利用者のファイル /

  - D3 の正には通信先の種類を付ける: 定数の外部ホスト / モデルが決める宛先 / モデルが決めるコード・コマンド / その他・不明。
- 手引きで決まらない事例は不明にし、§5 に記録する。手引きは判定の途中で変えない。

#### (f) 主指標と分母（宣言ごと。D1〜D4 を合算しない。D62、D67 の 3、D70 の 4・5）
- 判定した木の数を n、そのうち本当の矛（正）が 1 件以上あった木の数を k、宣言 d の矛が出た木の総数を N とする。
- 宣言 d を明示したユニットを 1 つ以上持つ走査した木の数を M_d とする。
- **主 (a)** = k / n。解析器が矛を出した木のうち、本当に違反があった木の割合。
- **主 (c)** = K̂ / M_d。K̂ = (k / n) × N で、n = N なら K̂ = k。宣言を書いた木のうち、違反が見つかった木の割合で、研究の問いへの答え。
- **参考 (b)** = K̂ / 走査した木の数。
- (a)〜(c) はどれも**下限**と明記する。理由は 2 つ。
  - 1 木 3 件までしか判定しない。
  - 矛の出なかった木の見落としを数えていない。
- 木ごとの精度 = 正 / (正 + 誤) の平均も出す。全部が不明の木は除き、その数を書く。
- **区間**: 木を単位にした bootstrap。反復 10,000 回、seed ④、百分位の 2.5% と 97.5%。
  - (b)(c) は、各回の (a) の値に N を掛けて分母で割る。
  - **【確認】** 木の数 n が 10 未満の宣言（D3・D4 で起こりうる）は、区間を出さずに件数だけを書く。
- **判定「不明」**（D70 の 5）: 精度の分母から除いた値を主にする。不明を誤とみなした値（正 / (正 + 誤 + 不明)）と、不明の件数を併記する。

#### (g) 参考と併記
- 件数: 宣言ごとの矛の総数、判定した件数、正 / 誤 / 不明、件数の精度と 95% Wilson 区間、誤の原因の内訳（E1〜E9）。
- 正の書き込み先の種類（D3 は通信先の種類）の内訳。条件の種類の内訳と (B)(C) の数。
- 見落とし: 200 件の内訳と見落としの原因、見落とし（深さ 4 の外）の件数。
  - 内訳は、反する動作は無い / 解析器が不として出している / 見落とし / 見落とし（深さ 4 の外）/ 不明。
  - 原因は、深さ / 呼び出しの解決 / 受け手の型 / 語彙 / その他。
- 不: 宣言ごとの全件の件数と理由の内訳。D1・D2 は判定した 100 組の結果（違反 / 違反でない / 不明、違反だった木の割合）。
  原理を 1 つずつ反対にしたときの矛の件数（感度分析、`scripts/contradiction_by_decl.py`）。
- `r_malformed`（§2.11）。V1 頑健性（打ち切り・parse 失敗・例外）。深さ 3・5 の矛の件数。
