#### (f) 主指標と分母（宣言ごと。D1〜D4 を合算しない。D62、D67 の 3、D70 の 4・5、D73 の 3・4）
- 判定した木の数を n、そのうち本当の矛（正）が 1 件以上あった木の数を k、宣言 d の矛が出た木の総数を N とする。
- 宣言 d を明示したユニットを 1 つ以上持つ走査した木の数を M_d とする。「明示した」は、解析器が矛を判定するときと同じ条件で
  決める（D73 の 3。既定値で補ったものは数えない）。
  - D1: `D_kind.explicit` に `readOnlyHint` がある（`readOnlyHint: true`）。
  - D2: `D_kind.explicit` に `destructiveHint` がある（`destructiveHint: false` で、`readOnlyHint: true` が無い）。
  - D3: `D_kind.closed_world` が真（`openWorldHint: false`）。`explicit` の `openWorldHint` は `openWorldHint: true` なので使わない。
  - D4: `D_kind.idempotent` が真（`idempotentHint: true` で、`readOnlyHint: true` が無い）。
- **主 (a)** = k / n。解析器が矛を出した木のうち、本当に違反があった木の割合。
- **主 (c)** = K̂ / M_d。K̂ = (k / n) × N で、n = N なら K̂ = k。宣言を書いた木のうち、違反が見つかった木の割合で、研究の問いへの答え。
- **参考 (b)** = K̂ / 走査した木の数。
- (a)〜(c) はどれも**下限**と明記する。理由は 2 つ。
  - 1 木 3 件までしか判定しない。
  - 矛の出なかった木の見落としを数えていない。
- 木ごとの精度 = 正 / (正 + 誤) の平均も出す。全部が不明の木は除き、その数を書く。(a) にも、判定した組が全部不明だった木の数を
  並べて書く（D76 の記録の形 9）。
- **区間**: 木を単位にした bootstrap。反復 10,000 回、seed ④、百分位の 2.5% と 97.5%。
  - (b)(c) は、各回の (a) の値に N を掛けて分母で割る。
  - 判定した木の数 n が 10 未満の宣言（D3・D4 で起こりうる）は、区間を出さずに件数と木ごとの内訳の表を書く（D73 の 4。
    まとまりが少ないと、木を単位にした bootstrap の幅は実際より狭く出やすいため）。
- **判定「不明」**（D70 の 5）: 精度の分母から除いた値を主にする。不明を誤とみなした値（正 / (正 + 誤 + 不明)）と、不明の件数を併記する。

#### (f2) 実態調査の指標（D1。D82）
- 判定した件の数を n_s（列の先頭から実際に判定した件）とする。区間はどれも 95% Wilson（1 木 1 件なので件は独立）。
- **主: 実態** = 違反 / (違反 + 違反でない)。「D1 を明示したサーバから無作為に 1 ツールを選んだとき、そのツールが D1 に反する割合」。
  - 併記: 不明を全部違反でないとした値と、全部違反とした値（幅）。不明の件数。

#### (h) やってはいけないこと
- 走査の後に、解析器・原理・判定表・語彙・手引きを変える（手引き 22 の 3 の手続きで規則を足す場合を除く）。
- 結果を見て、抜き取り・seed・分母を変える。
- 判定に迷った件を黙って正か誤に倒す。
- AI に判定させる。AI の答えを確かめずに記録する。宣言の値や解析器の答えを AI に渡す。
- 事前登録に無い分析を「事前登録した」と書く。事後の分析は分けて書く。
- 判定の途中で集計を見る。
- 実態調査の判定を終える前に、最終評価の解析器の出力（判定表の矛・不、summary、contradictions、道筋のファイル）を見る（D82）。
- 実態調査の判定を、結果を見て止める（止めてよい理由は時間だけ）。
