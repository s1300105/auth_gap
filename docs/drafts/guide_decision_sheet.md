# 判定の手引き（下書き）の決定シート

手引きの下書き（`docs/drafts/final_judging_guide_draft.md`）を封をする前に、学生が決めることだけを集めた。目安は 1 時間（問 1〜12 に 40 分、一括の承認に 20 分）。
答え方: 小問ごとに A / B / C の記号で答える。「わからない → 不明のまま」でもよい（決めずに封をし、出会ったら手引き 22 節で不明にして §5 に記録する）。
表の中では選択肢を並べただけで、本記録者の推奨は最後の「推奨のまとめ」に分けて書いた（**「推奨どおり、ただし 6(a) は B」のように答えれば済む**）。「v4 で」の数は開発用のデータ（v4、88 木）だけから数えた。数え方と、穴 155 個・食い違い 13 件の全部の仕分けは `docs/drafts/guide_holes_triage.md`（読まなくてよい）。
